## 四、★ 三条铁律

### 铁律 1：不许等到"准备好了"再投简历

补录批不等人。**项目做到 60% 就开始投**（11 月中旬起）。

### 铁律 2：简历上每个数字都要能讲清口径

面试官会一路追到底：
```
"你写召回率从 62% 提到 89% —— 62% 是哪个数据集？
 多少条？召回率怎么定义的？Top-K 的 K 是多少？谁标注的？"
```
**只报结论不报口径 = 减分项。**

### 铁律 3：学习的终点是"能讲"，不是"能跑"

项目跑通只完成 60%。
剩下 40% 是：写清 README、填满追问链自查表、练到脱稿能讲 20 分钟。
