# 阶段三 · 冲刺期（2027.05 – 2027.09）

> **独特目的**：把前 8 个月的积累换成 offer。
> 这个阶段的重点工作**不再是学习**，而是"包装、投递、面试、复盘"。

---

## 一、这个阶段的残酷真相

**面试考的不是你懂多少，而是你能讲清楚多少。**

见过太多人：项目做得很扎实，但面试时讲不清设计动机，讲不出数据，被追问两句就慌 —— 然后被判"基础不扎实"。

所以这 5 个月的核心动作是：
- **把已有项目讲到滚瓜烂熟**（不是学新的）
- **刷题刷出肌肉记忆**
- **海投 + 每场复盘**

---

## 二、5–6 月：实习入职 + 简历打磨

### 如果拿到了暑期实习

**这是最好的情况，请把握住。**

实习期间要做的（**这决定了能不能转正**）：

| 要做 | 不要做 |
| --- | --- |
| **主动要任务**，不要等派活 | 只做完被分配的、多余的绝不碰 |
| 把分配的任务**做到超出预期** | 卡着 deadline 交 |
| 遇到问题**先自己查 30 分钟再问** | 每个小问题都立刻打断别人 |
| **每天记录**遇到的工程决策和踩坑 | 干完就忘，实习结束两手空空 |
| 主动读团队的代码和文档 | 只碰自己那一小块 |
| 问导师"这个设计为什么这样" | 从不提问（显得没兴趣） |

**★ 关键**：实习结束时，你要能说出 3 个具体的技术细节和 1 个你独立解决的问题。这些是秋招简历上最值钱的内容。

**转正的关键时机**：一般在实习结束前 2 周就要主动和 leader 沟通转正意向，**不要被动等**。

### 如果没拿到实习

不要慌，还有路：
- **找小公司/创业公司的实习**（门槛低，但能接触真实业务）
- **做开源贡献**（给知名项目提 PR，简历上很亮眼）
- **接真实项目**（帮老师做、帮企业做，都算项目经历）
- **把项目做到更深的程度**（有真实用户、有持续迭代）

**绝对不能做的**：在家"再学一学"。没有产出的话，学得再多简历也是空白。

### 简历制作要点

**一页纸，技术岗不要两页。**

结构：
```
姓名 | 电话 | 邮箱 | GitHub | 博客(可选)
—————————————————————
教育背景（学校/专业/时间/GPA如果有优势就写）
—————————————————————
专业技能（分类写，别堆砌）
  编程语言：Python（熟练）、SQL（熟练）、...
  AI相关：RAG、Agent、Function Calling、...
  工程：FastAPI、Docker、Git、Linux、...
—————————————————————
项目经历（2-4 个，每个 3-4 条 bullet）
  项目名 | 时间 | 技术栈
  • 解决什么问题（一句话）
  • 技术方案与关键决策
  • ★量化结果
—————————————————————
实习经历（如果有，放在项目之前）
—————————————————————
其他（竞赛/论文/证书，有就写，没有别硬凑）
```

**简历四个致命问题**：
1. **没有数字** —— "提升了效果" 改成 "召回率从 62% 提升到 89%"
2. **写成职责而非成果** —— "负责后端开发" 改成 "实现 XX 接口，QPS 达到 XXX"
3. **技术栈堆砌** —— 写了 20 个技术但面试问哪个都不会，是负分
4. **项目没有区分度** —— 四个项目全是 RAG，等于一个项目

## 三、刷题：从 5 月刷到 9 月，不要停

**目标：LeetCode Hot 100 全部掌握 + 中等题熟练。**

| 阶段 | 目标 | 每天 |
| --- | --- | --- |
| 5–6 月 | 打基础，按类别刷 | 2–3 题 |
| 7–8 月 | Hot 100 过完一轮，开始二刷 | 3–5 题 |
| 9 月 | 保持手感，只做复习和模拟 | 2 题 |

**按类别刷的顺序**（不要乱刷）：
1. 数组 / 双指针 / 滑动窗口
2. 哈希表
3. 链表
4. 二叉树（递归思维）
5. 栈与队列
6. 动态规划（最难，放最后，只求常见题）
7. 排序 / 二分查找

**关键原则**：
- **刷题是手感活**，停一周就废，宁可每天 2 题也不要周末猛刷 20 题
- **不要看答案超过 20 分钟**（超时就去看题解，理解了再手写一遍）
- **每道题的解法要能口述**（面试是边说边写）

> 大模型应用岗的算法题通常比纯后端岗**简单一些**，但**一定会考**。别抱侥幸心理。

## 四、八股准备：考什么、怎么准备

### 计算机基础（必考）

| 科目 | 高频考点 |
| --- | --- |
| 计算机网络 | TCP 三次握手/四次挥手、HTTP vs HTTPS、HTTP 状态码、GET vs POST |
| 操作系统 | 进程 vs 线程、死锁、内存管理、IO 模型 |
| 数据库 | 索引原理（B+树）、事务 ACID、隔离级别、慢查询优化 |
| 数据结构 | 常见结构的时间复杂度（刷题时会自然掌握） |

**准备方式**：不用啃书。找一份整理好的面试八股文档，**用自己的话复述一遍**，能讲清楚就行。

### LLM / AI 应用相关（必考，且是你最能得分的地方）

| 主题 | 你必须能回答的问题 |
| --- | --- |
| RAG | 完整流程是什么？embedding 怎么选？chunking 怎么切？为什么需要混合检索？rerank 的作用？ |
| 检索评测 | 召回率怎么算？你怎么知道你改进了？ |
| Agent | ReAct 是什么？循环怎么终止？工具调用失败怎么办？ |
| Function Calling | 模型是怎么"调用"工具的？参数格式是什么？ |
| 上下文 | 上下文窗口的代价？怎么管理长对话？ |
| 微调 | 什么时候该微调？LoRA 是什么？SFT 和 DPO 区别？（知道概念即可） |
| 部署 | 显存怎么估算？量化有哪些方式？vLLM 为什么快？ |
| 幻觉 | 为什么模型会编？RAG 为什么能缓解？还有其他办法吗？ |
| 成本 | 怎么控制 token 成本？本地部署 vs API 怎么选？ |
| 评测 | 怎么评测一个 LLM 应用？LLM-as-judge 可靠吗？ |

**准备方式**：**用你自己的项目来回答**。
不要说"我背过 RAG 的流程"，要说"**我做的项目里，一开始只用向量检索，发现专有名词召回很差，所以加了 BM25…**"。
**把八股变成你的项目故事** —— 这是应用岗面试的高分技巧。

### 项目深挖（面试的主要部分）

面试官会挑一个项目**问 20 分钟**，你要准备好这些问题的答案：

- 这个项目解决什么问题？为什么要做？
- 为什么选这个技术方案？考虑过别的吗？代价是什么？
- 数据量多大？效果怎么衡量的？指标怎么定义的？
- 最大的难点是什么？（**要准备一个真实的技术故事**）
- 如果数据量涨 100 倍，哪里先崩？
- 如果重做一遍，你会改什么？
- 成本是多少？怎么优化的？

**如果答不上来"最大的难点"**，面试官会认为你没真正做过。

## 五、投递策略（关键）

### 海投，不要挑

**本科应届生没有挑公司的资格。**

投递组合建议：
```
30% 大厂（字节/阿里/腾讯/百度/美团/华为等）
40% 中厂（上市公司、细分领域龙头）
30% AI 创业公司（最容易被捞，也最能学东西）
```

**目标数量**：
- 暑期实习：**30–60 家**
- 秋招提前批：**20–40 家**
- 秋招正式批：**60–100 家**

被拒是常态。**投 100 家拿到 10 个笔试、5 个面试、1-2 个 offer，就是正常水平。**

### 投递渠道

| 渠道 | 特点 |
| --- | --- |
| 公司官网/招聘公众号 | 最权威，提前批常在这里 |
| BOSS 直聘 | 反馈快，适合中厂和创业公司 |
| 牛客网 | 校招信息集中，有内推码 |
| 学长学姐内推 | ★最有效，内推能跳过简历筛选 |
| 实习僧 / 拉勾 | 实习为主 |

**内推是杠杆**：同一份简历，内推的响应率能高好几倍。**主动去加学长学姐、加技术群。**

### 投递节奏

- **提前批大胆投**：很多公司提前批挂了不影响正式批，是纯赚的
- **每天固定时间投**（比如晚上 1 小时），不要碎片化
- **建一个投递记录表**：公司 / 岗位 / 投递日期 / 状态 / 面试问题

## 七、8–9 月：秋招正式批

### 时间节奏

| 时间 | 动作 |
| --- | --- |
| 8 月上旬 | 提前批投递（如果有） |
| 8 月中–9 月 | 正式批海投，笔试密集期 |
| 9 月–10 月 | 面试密集期，可能一天两三场 |
| 10 月–11 月 | 补录、捡漏、offer 比较 |

### 面试密集期的心态管理

- **一天两三场面试很累，但正常** —— 提前排好时间，别撞车
- **被拒不要停** —— 拒信和 offer 往往在同一周到达
- **拿到第一个 offer 后心态会稳很多** —— 所以先投相对容易的，拿个保底

### Offer 评估维度

| 维度 | 权重 | 说明 |
| --- | --- | --- |
| **技术成长** | ★★★★★ | 应届生第一份工作最重要的是学到东西 |
| **团队/业务** | ★★★★☆ | 做 AI 相关吗？有真实落地场景吗？ |
| 薪资 | ★★★☆☆ | 重要但不是唯一，别为多 2k 去一个学不到东西的地方 |
| 稳定性 | ★★★☆☆ | 大厂裁员也不少，创业公司可能倒闭 |
| 城市 | ★★★☆☆ | 考虑生活成本和长期发展 |

**给应届生的建议**：**第一份工作选"能让你第二年更值钱"的那个**，而不是"现在钱最多的那个"。

## 九、最后一句实话

这个阶段最难的**不是技术**，是**心态**。

你会经历：投出去的简历石沉大海、面试被问懵、看着别人拿 offer 而自己还在等。

**这些全都正常。**

应届生从开始投到拿到 offer，平均要经历 **50–100 次投递、10–20 场面试**。被拒不是对你的否定，只是概率。

18 个月之后，**只要你不中途停下**，你一定会有工作。

—— 本鱼说的。
